Installing from Windows

You need: AutoBleemInstaller on a PC, a USB stick for the console
psc-1.1
Start the installer.You should see: The channel is chosen for you; after a few seconds the status says what it would install ("A fresh install of AutoBleem v...").
psc-1.2
Switch between the three channels (Release, Testing, Nightly).You should see: The version in the status changes. Release says it has nothing to install.
psc-1.3
Use a fresh stick, choose Testing and press Install.You should see: The package is downloaded and checked, then unpacked; the stick is named SONY and the console boots it.
psc-1.4
Run the installer again over the same stick, with Nightly.You should see: It says which version is on the stick and what it will update to. After Update your games, saves and settings are still there.
psc-1.5
Unplug the network cable or turn Wi-Fi off and start the installer.You should see: The status says there is nothing to install and mentions the internet. Install stays greyed out.

Updating on the console

You need: a console with AutoBleem and Wi-Fi set up in PSC-Bios
psc-2.1
Open PSC-Bios (L2+R2, then Hardware Information) and connect to Wi-Fi.You should see: PSC-Bios shows an IP address.
psc-2.2
Open Options, then Updates.You should see: The row is there, with release / testing / nightly / off.
psc-2.3
Choose nightly, go back to the carousel and wait up to a minute.You should see: An "Update available" dialog shows both versions.
psc-2.4
Choose "Remind me tomorrow".You should see: The dialog goes away and does not come back when you restart the launcher.
psc-2.5
Choose "Update now".You should see: A download bar is shown; the launcher closes, the AutoBleem picture stays while the stick is updated (up to a few minutes), then the launcher returns.
psc-2.6
Open About.You should see: It shows the new version. Games, save states, memory cards, the theme and settings are unchanged.
psc-2.7
Turn Wi-Fi off, then press L2+R2 and choose Software Update.You should see: "Not connected". No dialog at start and nothing slows down.
